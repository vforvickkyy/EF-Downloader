Google API key optional

Everything works without a key. A free key from Google makes very large folders list reliably, shows exact sizes before you start, and scans faster.

How to get a free key (about 2 minutes)
  1. Open Google Cloud Console and create a project (any name).
  2. Turn on the Google Drive API for it.
  3. Go to Credentials → Create credentials → API key.
  4. Copy the key, paste it above, then Test and Save.
The key only reads public files. No sign-in, no billing needed.
